## Key Functions / Classes

| Symbol | Purpose |
|------|------|
| `swap_from_dopt(model, dopt_path)` | Main path (shared by scenario 1/2): one load sd → Linear swap + Embedding extraction, returns `(quant_info, embed_quant)` |
| `swap_embeddings_from_dopt(sd, model)` | W8 host gather for embed_tokens (does not replace with a graph module) |

| `materialize_int4_per_group_symmetric(weight, scale, group_size, ...)` | Quantize with lightweight tool pre-computed scale (main path) |
| `materialize_int8_per_channel_symmetric(weight, scale)` | 8-bit per-row symmetric quantization (for embed) |
| `QuantLinear(nn.Module)` | Export surrogate, forward calls `npu::npu_quant_matmul` + `npu::npu_dynamic_quant` |

## Quantization Scheme

| Side | Bit-width | Granularity | Symmetric | Scale source |
|----|------|------|------|-------------|
| Weight (x2) | int4 (s4) | per-channel × per-group (default 128) | symmetric (offset=0) | GPTQ offline (`group_scale`) |
| Activation (x1) | int8 (s8) | per-token dynamic | symmetric | Runtime `npu_dynamic_quant` → `DynamicQuant` IR |
| Output | fp16/bf16 | — | — | — |

> Path C': reuse CANN native `npu::npu_quant_matmul` → `ge.QuantBatchMatmulV4` (V4 full IR + dummy bias workaround). The earlier scheme A (in-house `quant_matmul_s8s4`) is deprecated; its spec is retained as a historical archive.
